# StudyBuddy · 轻量日志笔记

一个**零依赖、零安装**的手机日志笔记应用。随手记一条，内容里带 `#标签` 就自动分类，
数据只存在你自己的设备上，不联网、不上传。

---

## 一、立刻用起来

**电脑上**：双击 `index.html`，浏览器打开就能写。想把它当正式应用跑（能用离线缓存、
能"安装"到主屏幕），用任意静态服务器打开，例如：

```bash
cd D:\claude-work\studybuddy
python -m http.server 8080
# 然后浏览器访问 http://localhost:8080
```

**手机上**：把这个目录放到任意静态托管上（或由 WorkBuddy 发布成在线链接），
手机浏览器打开后选「添加到主屏幕」，就是一个独立图标、全屏运行、断网也能用的 app。

## 二、功能

| 功能 | 说明 |
|---|---|
| 快速记录 | 底部输入框写内容，点「发送」（电脑上按 Enter 也行，Shift+Enter 换行） |
| **全屏倒计时 / 沉浸模式** | 点番茄钟里的圆环（或提示「点击放大 ⤢」）进入全屏：只有大数字，**沉浸态**下按钮会淡出、点屏幕唤出、6 秒无操作自动回沉浸；计时中**保持屏幕常亮**；支持**原生全屏 + 横屏布局**（圆环在左、信息在右），退出时自动解除屏幕方向锁 |
| **番茄入口（显眼）** | 顶部有一条大按钮：空闲时显示「开始一个番茄钟 · 25 分钟」，计时中变成蓝色呼吸条，显示「专注中 · 科目 · 任务名」+ 剩余时间 + 底部进度条，休息时变绿；点一下即开番茄钟弹层 |
| **科目维度** | 录入前先点一个科目（政治 / 英语二 / 数学二 / 半导体物理 / 其他），记录、筛选、番茄钟都能按科分类；顶部筛选行可按科目或标签筛 |
| 考试倒计时 | 顶部显示「距 27 考研初试 N 天」，点一下可改日期；弹层里附考研关键节点（预报名 / 报名 / 确认 / 准考证） |
| **每日目标** | 每天要做的固定任务（背单词 / 阅读 / 数学一章…），打勾、看完成率，**每天零点自动重置**（页面一直开着也会自动刷新）；顶部也显示 x/y |
| 自动分类 | 内容里写 `#英语` `#读书` 这类标签，会**自动**提取并在列表里显示 |
| 搜索筛选 | 顶部搜索框搜内容或标签；科目、标签点一下就只看这一类 |
| 编辑删除 | 每条记录右下角「编辑」，能改内容和科目；**删除后 5 秒内可「撤销」** |
| 时间分组 | 列表按「今天 / 昨天 / 具体日期」分组，每条带时间 |
| 打卡统计 | 顶部显示今天几条、总共几条、连续记录多少天、今日番茄数、今日目标完成度 |
| **番茄钟** | 先选科目、给这次专注起个名字（如「极限 30 题」，最近用过的会变成快捷标签，点一下复用），专注时长可选 15 / 25 / 45 分钟，也能**自定义 1~180 分钟任意值**；休息 5 分钟、每 4 个番茄长休 15 分钟；圆环倒计时（环里显示这次的任务名）、结束有声音+振动提醒；可设置成**每完成一个番茄自动往日志记一条**（默认开） |
| **完成的学习日程** | 🍅 弹层里点「学习日程」，或 ⋯ 菜单进入：每个完成的番茄自动记一条，按天分组，显示**起止时间 / 时长 / 科目 / 任务名**，顶部有今日与累计汇总；可「复制日程」粘到微信收藏复盘，也能清空；**记录过多时最旧的自动归档**（不丢，只是移出列表，防止本地存储被撑爆） |
| **专注统计** | 番茄钟里点「专注统计」：今日 / 本周 / 本月 / 累计 的番茄数与专注时长 + **本周分科时长横条**（看有没有偏科）+ 最近 7 天柱状图；可一键清空统计（不影响日志） |
| **间隔复习** | 记录时点输入框右边的 **🔁** 开关，这条就进复习队列（首次排在**明天**）。到期后首页顶部出现「**今天该复习 N 条**」卡片，每条可「**记住了** / **还不熟** / **明天**」：记住了按 **1 / 2 / 4 / 7 / 15 / 30 / 60 天**往后推，还不熟就**回到第一轮**重来，走完 7 轮自动「毕业」。编辑弹层里能改档位（明天 / 3 / 7 / 15 / 30 天后）或移出队列；列表里带复习的笔记有 🔁 徽章（点一下改设置），顶部统计也有「🔁 待复习 N」 |
| **学习趋势** | 「专注统计」里新增三块：**本周 vs 上周**（两栏专注时长 + 涨跌百分比 + 一周七天的**双折线对比图**，本周实线 / 上周虚线）、**科目占比环形图**（本周，附百分比与分钟数图例）、**分科对比**（每科的本周 / 上周双条 + 涨跌箭头，一眼看出哪科在掉）；原来的最近 7 天柱状图保留 |
| 深浅色 | 右上角 ◐ 一键切换，默认跟随系统；全屏倒计时也跟着变亮/变暗 |
| **备份** | ⋯ → **复制备份到剪贴板**（手机最方便：粘到微信收藏/备忘录）/ 导出 JSON 文件 / 导出 Markdown / 从文件导入 / 从剪贴板导入；**3 天没备份会在 ⋯ 上亮小黄点并提醒** |
| 草稿保留 | 没写完就关掉页面（甚至直接杀掉浏览器），下次打开内容还在 |

## 三、数据在哪

- 存在浏览器本地的 **localStorage**，键名：
  `studybuddy.notes.v1`（记录，v3.1 起每条里多了 `reviewAt` / `reviewStage` / `reviewLast` 三个复习字段）/
  `studybuddy.pomolog.v1`（专注日志）/ `studybuddy.sessions.v1`（完成的学习日程）/
  `studybuddy.sessions.arc.v1`（日程自动归档区）/ `studybuddy.tasks.v1`（最近任务名）/ `studybuddy.exam.v1`（倒计时）/
  `studybuddy.subjects.v1`（科目）/ `studybuddy.goals.v1` + `studybuddy.goallog.v1`（每日目标与完成情况）；
- **不联网、不上传、没有账号**，换浏览器/换手机看不到彼此的数据；
- 所以：**定期备份**。最方便的是 ⋯ →「复制备份到剪贴板」，粘到微信收藏或备忘录里；
  换设备时复制那段文字 → ⋯ →「从剪贴板导入」即可（导入是合并，重复自动跳过，不会覆盖）。
  **3 天没备份，右上角 ⋯ 会亮小黄点提醒你。**

> 清浏览器数据、无痕模式、换设备都会导致记录丢失——这点务必记住。

## 四、工程结构

```
studybuddy/
├── index.html            主应用（HTML + CSS + JS 全内联，单文件可独立运行）
│                         v3.0 起：图标与 manifest **内联在页面里**（SVG + Blob），
│                         所以这个文件单独发出去也能「添加到主屏幕」
├── sw.js                 Service Worker：离线缓存（改了页面记得把 CACHE 版本号 +1，否则手机端会一直用旧缓存）
├── manifest.webmanifest  PWA 清单 —— v3.0 起 index.html 不再引用它（改为内联生成），
│                         保留作为打包/托管时的备用
├── icons/                应用图标（由 tools/make_icons.py 生成）—— 同上，v3.0 起不再被页面引用
│   ├── icon-192.png
│   ├── icon-512.png
│   └── favicon-64.png
├── archive/              存档：历次收到的其它迭代版（含来源与哈希说明）
├── tools/
│   └── make_icons.py     图标生成脚本（纯标准库，改配色后重跑即可）
└── README.md             本文件
```

> 页面里那句 `fetch("sw.js", {method:"HEAD"})` 探测：**托管时若 sw.js 存在就注册、不存在就跳过**，
> 所以单文件分发不会在控制台刷 404。

改图标：编辑 `tools/make_icons.py` 顶部的 `C1` / `C2` 配色，然后

```bash
python tools/make_icons.py
```

## 五、想变成真正的安卓 APK（可选）

现在它是"网页 App"，已经能满足绝大多数使用。若确实要一个能装到手机上的 APK，
最省事的路子是 **Capacitor** 套壳：

```bash
npm install -g @capacitor/cli
cd studybuddy
npx cap init StudyBuddy com.studybuddy.app --web-dir .
npx cap add android
npx cap sync
npx cap open android      # 用 Android Studio 打包 APK
```

前提是本机装好 Android Studio + SDK（约 6~8 GB，装在 D 盘）。
这条路我没替你走——需要的话说一声。

  离线可用性不变）、其它静态资源仍缓存优先；并且**安装时不再预缓存 `index.html`**
  （否则安装那一刻拿到旧副本就会被钉死）。缓存名 `v6 → v7`。
  ⚠️ 以后改页面：`index.html` 照常改，`sw.js` 的 `CACHE` 版本号也照常 +1。
