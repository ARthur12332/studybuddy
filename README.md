# StudyBuddy · 轻量日志笔记

一个**零依赖、零安装**的手机日志笔记应用。随手记一条，内容里带 `#标签` 就自动分类，
数据只存在你自己的设备上，不联网、不上传。

---

## 一、立刻用起来

**电脑上**：双击 `index.html`，浏览器打开就能写。想把它当正式应用跑（能用离线缓存、
能"安装"到主屏幕），用任意静态服务器打开，例如：

```bash
cd D:\claude-work\studybuddy
python -m http.server 8080
# 然后浏览器访问 http://localhost:8080
```

**手机上**：把这个目录放到任意静态托管上（或由 WorkBuddy 发布成在线链接），
手机浏览器打开后选「添加到主屏幕」，就是一个独立图标、全屏运行、断网也能用的 app。

## 二、功能

| 功能 | 说明 |
|---|---|
| 快速记录 | 底部输入框写内容，点「发送」（电脑上按 Enter 也行，Shift+Enter 换行） |
| **全屏倒计时 / 沉浸模式** | 点番茄钟里的圆环（或提示「点击放大 ⤢」）进入全屏：只有大数字，**沉浸态**下按钮会淡出、点屏幕唤出、6 秒无操作自动回沉浸；计时中**保持屏幕常亮**；支持**原生全屏 + 横屏布局**（圆环在左、信息在右），退出时自动解除屏幕方向锁 |
| **番茄入口（显眼）** | 顶部有一条大按钮：空闲时显示「开始一个番茄钟 · 25 分钟」，计时中变成蓝色呼吸条，显示「专注中 · 科目 · 任务名」+ 剩余时间 + 底部进度条，休息时变绿；点一下即开番茄钟弹层 |
| **科目维度** | 录入前先点一个科目（政治 / 英语二 / 数学二 / 半导体物理 / 其他），记录、筛选、番茄钟都能按科分类；顶部筛选行可按科目或标签筛 |
| 考试倒计时 | 顶部一条**窄条**（v4.0 起压到约 34px 高，数字仍主色加粗、名字退成次要灰），点一下可改日期；弹层里附考研关键节点（预报名 / 报名 / 确认 / 准考证） |
| **每日目标** | 每天要做的固定任务（背单词 / 阅读 / 数学一章…），打勾、看完成率，**每天零点自动重置**（页面一直开着也会自动刷新）；顶部也显示 x/y |
| 自动分类 | 内容里写 `#英语` `#读书` 这类标签，会**自动**提取并在列表里显示 |
| 搜索筛选 | 顶部搜索框搜内容或标签；科目、标签点一下就只看这一类 |
| 编辑删除 | 每条记录右下角「编辑」，能改内容和科目；**删除后 5 秒内可「撤销」** |
| 时间分组 | 列表按「今天 / 昨天 / 具体日期」分组，每条带时间 |
| 打卡统计 | 顶部显示今天几条、总共几条、连续记录多少天；后面三项是**能点的入口**（带一个小 ›）：**🍅 今日 N 个** → 专注统计、**🎯 目标 x/y** → 每日目标、**🔁 待复习 N** → 展开复习卡。其中「待复习」在有到期项时会变成**白底红字的小药丸**，一眼看到今天有东西要复习（点它而今天没有到期的，会告诉你队列里还排着几条） |
| **番茄钟** | 先选科目、给这次专注起个名字（如「极限 30 题」，最近用过的会变成快捷标签，点一下复用），专注时长可选 15 / 25 / 45 分钟，也能**自定义 1~180 分钟任意值**；休息 5 分钟、每 4 个番茄长休 15 分钟；圆环倒计时（环里显示这次的任务名）、结束有声音+振动提醒；可设置成**每完成一个番茄自动往日志记一条**（默认开）。**v4.0 起弹层分两层**：默认只留主路径「圆环 + 预设 + 本次专注 + 开始 / 重置 / 跳过」，时长选择、自定义时长、今日统计、自动记日志都折进 **「更多设置」**（收起时右侧小字直接写着当前是多少分钟、今天几个番茄，不用展开也知道）；一行引导语会跟着状态变（还没写任务 → 提示点预设；写好了 → 提示点开始；跑起来 → 自动让位） |
| **完成的学习日程** | 🍅 弹层里点「学习日程」，或 ⋯ 菜单进入：每个完成的番茄自动记一条，按天分组，显示**起止时间 / 时长 / 科目 / 任务名**，顶部有今日与累计汇总；可「复制日程」粘到微信收藏复盘，也能清空；**记录过多时最旧的自动归档**（不丢，只是移出列表，防止本地存储被撑爆） |
| **主题色** | ⋯ →「外观」里可以换**主题色**：蓝紫（默认）/ 海蓝 / 青绿 / 松绿 / 暖橙 / 玫红，共 6 套。换色同时改变顶栏、番茄钟条、按钮、图表、全屏倒计时的圆环与光晕；**深浅色各有一套取值**（深色底上用更亮的主色，保证对比度），两层可以随意搭配。同一面板里还能选**跟随系统 / 浅色 / 深色** |
| **番茄钟预设** | 番茄钟弹层顶部有一排预设（默认给了「数学二 一章 / 英语阅读 1 篇 / 政治 1 讲 / 半导体物理 1 章」）。每个预设自带**名称 + 时长 + 科目**，**点一下就直接开始专注并进入沉浸倒计时**，不用每次重选科目、重填名字、重设时长；右边的 **＋** 展开**页内管理面板**（v3.4 起），添加、删除都在番茄钟这一页里完成，「用当前设置」按钮能一键把现在的科目/时长/名字填进表单（最多 12 个，按名字去重）；面板展开/收起、新增与删除都带动效（v4.0.2，＋ 顺手转成 ✕） |
| **专注统计** | **三个入口**（v4.0）：番茄钟里的「专注统计」按钮、⋯ 菜单 →「查看 / 专注统计」、顶栏「🍅 今日 N 个」。内容：今日 / 本周 / 本月 / 累计 的番茄数与专注时长 + **本周分科时长横条**（看有没有偏科）+ 最近 7 天柱状图；可一键清空统计（不影响日志） |
| **首次使用引导** | 一条记录都没有、且没点过「知道了」时，首页顶部出现三步卡片（选科目 → 写一句 → 用 🔁 排复习）；点「知道了，不再显示」永久收起，写下第一条记录后也会自动退场（v4.0） |
| **间隔复习** | 记录时点输入框右边的 **🔁** 开关，这条就进复习队列（首次排在**明天**）。到期后首页顶部出现「**今天该复习 N 条**」卡片，每条可「**记住了** / **还不熟** / **明天**」：记住了按 **1 / 2 / 4 / 7 / 15 / 30 / 60 天**往后推，还不熟就**回到第一轮**重来，走完 7 轮自动「毕业」。编辑弹层里能改档位或移出队列 —— **档位就是算法自己那套**（明天 / 2 / 4 / 7 / 15 / 30 / 60 天后，v4.0 起与 `REV_STEPS` 同源，算法推得出的天数一定有对应档位），档位上方还有一行**「当前：4 天后（09/28）· 第 3/7 轮」**，所以即使遇到导入的旧数据也能一眼看清真实状态；列表里带复习的笔记有 🔁 徽章（点一下改设置） |
| **学习趋势** | 「专注统计」里新增三块：**本周 vs 上周**（两栏专注时长 + 涨跌百分比 + 一周七天的**双折线对比图**，本周实线 / 上周虚线）、**科目占比环形图**（本周，附百分比与分钟数图例）、**分科对比**（每科的本周 / 上周双条 + 涨跌箭头，一眼看出哪科在掉）；原来的最近 7 天柱状图保留 |
| 深浅色 | 右上角 ◐ 一键切换，默认跟随系统；全屏倒计时也跟着变亮/变暗 |
| **⋯ 菜单（v4.0 分组）** | 菜单按用途分成四组：**查看**（学习日程 / 专注统计）、**设置**（每日目标 / 科目 / 外观）、**数据**（复制备份 / 导出 JSON / 导出 Markdown / 从文件导入 / 从剪贴板导入）、**危险操作**（清空全部）。菜单里全是按钮、没有输入框，所以**点空白处即可关闭**（其它弹层仍保持「点遮罩不关」的防误触策略）；原来底部那行多余的「关闭」已删除 |
| **备份** | ⋯ → **复制备份到剪贴板**（手机最方便：粘到微信收藏/备忘录）/ 导出 JSON 文件 / 导出 Markdown / 从文件导入 / 从剪贴板导入；**3 天没备份会在 ⋯ 上亮小黄点并提醒** |
| 草稿保留 | 没写完就关掉页面（甚至直接杀掉浏览器），下次打开内容还在 |

## 三、数据在哪

- 存在浏览器本地的 **localStorage**，键名：
  `studybuddy.notes.v1`（记录，v3.1 起每条里多了 `reviewAt` / `reviewStage` / `reviewLast` 三个复习字段）/
  `studybuddy.pomolog.v1`（专注日志）/ `studybuddy.sessions.v1`（完成的学习日程）/
  `studybuddy.sessions.arc.v1`（日程自动归档区）/ `studybuddy.tasks.v1`（最近任务名）/
  `studybuddy.presets.v1`（番茄钟预设，v3.2 新增）/ `studybuddy.exam.v1`（倒计时）/
  `studybuddy.subjects.v1`（科目）/ `studybuddy.goals.v1` + `studybuddy.goallog.v1`（每日目标与完成情况）；
  另有界面偏好三个键：`studybuddy.theme`（auto / light / dark）、`studybuddy.accent`（主题色 id，v3.3 新增）、
  `studybuddy.guide.seen`（首次引导是否已点掉，v4.0 新增）；
- **不联网、不上传、没有账号**，换浏览器/换手机看不到彼此的数据；
- 所以：**定期备份**。最方便的是 ⋯ →「复制备份到剪贴板」，粘到微信收藏或备忘录里；
  换设备时复制那段文字 → ⋯ →「从剪贴板导入」即可（导入是合并，重复自动跳过，不会覆盖）。
  **3 天没备份，右上角 ⋯ 会亮小黄点提醒你。**

> 清浏览器数据、无痕模式、换设备都会导致记录丢失——这点务必记住。

## 四、工程结构

```
studybuddy/
├── index.html            主应用（HTML + CSS + JS 全内联，单文件可独立运行）
│                         v3.0 起：图标与 manifest **内联在页面里**（SVG + Blob），
│                         所以这个文件单独发出去也能「添加到主屏幕」
├── sw.js                 Service Worker：离线缓存（改了页面记得把 CACHE 版本号 +1，否则手机端会一直用旧缓存）
├── manifest.webmanifest  PWA 清单 —— v3.0 起 index.html 不再引用它（改为内联生成），
│                         保留作为打包/托管时的备用
├── icons/                应用图标（由 tools/make_icons.py 生成）—— 同上，v3.0 起不再被页面引用
│   ├── icon-192.png
│   ├── icon-512.png
│   └── favicon-64.png
├── archive/              存档：历次收到的其它迭代版（含来源与哈希说明）
├── tools/
│   └── make_icons.py     图标生成脚本（纯标准库，改配色后重跑即可）
└── README.md             本文件
```

> 页面里那句 `fetch("sw.js", {method:"HEAD"})` 探测：**托管时若 sw.js 存在就注册、不存在就跳过**，
> 所以单文件分发不会在控制台刷 404。

改图标：编辑 `tools/make_icons.py` 顶部的 `C1` / `C2` 配色，然后

```bash
python tools/make_icons.py
```

## 五、想变成真正的安卓 APK（可选）

现在它是"网页 App"，已经能满足绝大多数使用。若确实要一个能装到手机上的 APK，
最省事的路子是 **Capacitor** 套壳：

```bash
npm install -g @capacitor/cli
cd studybuddy
npx cap init StudyBuddy com.studybuddy.app --web-dir .
npx cap add android
npx cap sync
npx cap open android      # 用 Android Studio 打包 APK
```

前提是本机装好 Android Studio + SDK（约 6~8 GB，装在 D 盘）。

## 六、版本

- **v4.0.2（2026-09-23）动效：把「唰一下出现」改成「看得出来它是怎么出来的」**
  起因是点 ＋ 展开预设管理面板时，下面的内容被瞬间顶开 —— 突兀。照着这个手感把同类地方一起收拾了：

  1. **两个折叠区改走同一套过渡。** 预设管理面板和「更多设置」原来是 `hidden` 一翻了事，
     现在是高度（`grid-template-rows: 0fr → 1fr`）+ 淡入 + 轻微上浮，约 300ms；
     收起时反向演一遍，**演完才真正 `hidden`**（不然动画会被打断）。
     内边距也跟着收（用 `--pad-t/--pad-b` 变量），所以收起态是**真 0 高度**、不占位。
     ＋ 旋转 45° 变 ✕ 的那点手感没动，还是原来那个。
  2. **新增预设看得见落点。** 新加的那条在预设条上弹入（`presetPop`），
     管理列表里对应的行滑进来；预设条是横向滚动的，新条目还会自动滚进视野。
  3. **删除不再「跳」。** 点删除时那一行先高度收起 + 淡出（180ms），再真删；
     5 秒内点撤销，恢复的那一条会再弹回来，一眼看出回来的是哪条。
  4. **连点不会互相打断。** 收起动画途中再点开，不会出现「刚展开又被上一次的延时隐藏吞掉」
     （隐藏定时器按元素存、开的时候先清掉）。
  5. **无障碍兜底。** 新增 `@media (prefers-reduced-motion: reduce)`：
     系统里开了「减少动态效果」就只保留状态变化，不留花活。

  测试方式：`_probe_anim.html` 两遍跑同一个文件 —— 普通模式验状态机（`.open`/`hidden` 时序、
  动画真的挂上、连点不丢状态），`#notrans` 模式（注入 `transition:none`）量「展开后的终点」
  （高度 370px、透明度 1、内边距 11/12）。**无头环境的过渡时间轴不随虚拟时钟走，
  只看中间帧会把应用判成坏的** —— 这个坑这次又踩了一遍。

- **v4.0.1（2026-09-23）一次专项 bug 巡查修出来的 4 个真 bug + 1 处前后不一致**
  把 v4.0 从头到尾按「真点一遍 + 边角数据」跑了一轮（首页、番茄钟、6 个弹层、复习、主题、跨天、
  恶意/破损导入、数值脏数据），修掉下面这些：

  1. **统计弹层会被一条坏数据整个打空（严重）。** `pomoLog` 读进来时只判断了「是个对象」，
     里面某一天的值是 `null`（手工改过、或跨设备合并出来的备份都可能）时，
     `sumAllPomo()` 直接 `.count` 就抛异常 —— 「专注统计」弹层打开是**一片空白**、控制台一条红字。
     现在 `pomoLog` 和 `sessions` 读入/导入都过一遍统一的清洗（只留日期键、数字取有限非负整数、
     `subj` 逐项过滤），`sumAllPomo` / `sumKeys` / `dayMinutes` 也加了兜底。
  2. **日程里的脏数字显示成 NaN。** `sessions` 原来只筛 `x.minutes` 为真，
     字符串 `"abc"` 能过，于是「已完成 NaN 小时」、单条显示成 `--:-- abc 分钟`；
     负数还会算成「-30 分钟」。现在 `minutes` 必须是有限正数、日期必须能解析，坏记录直接丢弃
     （`mergeSessions` 的导入路径也走同一套校验）。
  3. **考完之后倒计时两侧自相矛盾。** 条子左边硬写着「天后」，右边却写「已考完 5 天」；
     而且 `urgent` 的条件是 `left <= 100`，负数也满足，所以考完以后高亮边框一直亮着。
     现在单位跟着正负走（「天后 / 天前」），`urgent` 只在 `0 ≤ left ≤ 100` 时亮。
  4. **毕业的笔记在编辑弹层里显示成「未排入复习」。** 走完 7 轮毕业的笔记 `reviewAt` 是空的，
     弹层只按「有没有 reviewAt」判断，于是显示「当前：未排入复习」——
     看起来像从没排进过复习队列。现在显示「当前：已毕业（7 轮都复习完了）」，
     提示语也跟着改成「想再刷一遍就随便选个档位，会从第一轮重新开始」。
  5. 顺手：首次引导卡改成双向判断（没记录、也没点过「知道了」才出现）——
     原来只负责「有记录就藏」，于是把记录全删光之后引导卡要等刷新才回来。

- **v4.0（2026-09-23）入口归位 + 跨天修复 + 首页瘦身**
  起因是拿一份第三方 AI 提的优化清单逐条核对代码：方向判对了（问题不在「缺功能」，而在「东西没归位」），
  但它漏了最显眼的一个真 bug，还把唯一那个「会改坏数据」的坑降级成了视觉问题。这一版把两边的 P0/P1 都做了：

  **P0（真问题）**
  1. **跨天刷新一次修全。** 原来 `tickPomoCross` 只补 `renderGoals()`，漏掉的比补上的多：
     考试倒计时「还有 N 天」不会变（首页第一眼就看到的东西）、列表里 🔁 徽章的相对天数不会变
     （隔夜后「1 天后」应该变成「今天该复习」）。现在改成直接 `render()` —— 它串起
     renderStats / renderChips / renderExam / renderReviewCard / renderList（目标卡在里面），
     一次全部归位，不靠人肉列举。另外基线日在**脚本加载时**就定下来（原来要等第一次 tick 才「上膛」，
     恰好卡零点打开的话第一次 tick 只会把基线填成新的一天然后 return，昨天的视图就永远留在那儿），
     并补了 `visibilitychange` → 立刻查一次跨天（页面在后台时定时器会被节流甚至冻结）。
  2. **复习档位与算法同源。** 原来弹层里的档位是手写的 `1/3/7/15/30`，而算法实际推的是
